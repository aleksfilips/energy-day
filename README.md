# Энергия дня — личный лунный календарь

Мини-приложение Telegram и PWA для всех: каждый человек при первом запуске вводит своё место и дату рождения
и получает свой день. Каждый день простым языком: какой сегодня день, что благоприятно по 20 сферам жизни
(дела, деньги, здоровье, отношения, дом, стрижка, сад, сны), когда удачное время для важного, восход и закат,
ближайшие новолуния и полнолуния, личный день, дневник. Лунные дни, фаза, знак, Луна без курса и затмения
считаются астрономически для твоего места. Всё считается на устройстве.

```bash
npm install
npm run dev          # локально, http://localhost:5173
npm test             # 400+ тестов: астрономия, сверка, контент, синтез, закономерности
npm run build        # сборка в dist/
npm run verify       # отчёт сверки с эталонами (см. VERIFICATION.md)
npx tsx scripts/morning.ts 57.13 60.15 Asia/Yekaterinburg 30.06   # текст утреннего сообщения
```

## Устройство

- `src/astro/` — слой А, факт: фазы, восходы, лунные сутки, знак, ингрессии, VOC, затмения, апсиды, титхи, накшатры, сад.
- `src/content/` — слой Б, традиция: zod-схемы и JSON всех толкований, наложение правок.
- `src/synthesis/` — модель дня, правила «Энергии дня», простой план (`life.ts`) и оценки сфер (`areas.ts`).
- `src/personal/` — личный день по нумерологии Л. Хей.
- `src/diary/` — дневник, закономерности, экспорт.
- `src/places/` — поиск мест, часовые пояса (таблица субъектов РФ), исторические переводы часов.
- `src/bot/` + `scripts/bot.ts` — бот: подписка по коду из приложения и утренние сообщения каждому.
- `src/app/` — интерфейс (React + Tailwind), `src/telegram.ts` — связка с Telegram.
- `DECISIONS.md` — методика и допущения. `VERIFICATION.md` — сверка с эталонами.

## Публикация в Telegram (один раз)

1. Репозиторий на GitHub → Settings → Pages → Source: **GitHub Actions**. После пуша в `main`
   приложение появится по адресу `https://<логин>.github.io/<репозиторий>/`.
2. В Telegram у [@BotFather](https://t.me/BotFather): `/newbot` → имя и логин бота → получишь токен.
   Логин бота впиши в `src/config.ts` (`BOT_USERNAME`), адрес сайта — туда же (`SITE_URL`).
3. Там же: `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App** → адрес из шага 1.
   Тогда ссылка-приглашение `t.me/<бот>?startapp` сразу открывает приложение.
   И **Bot Settings → Menu Button** → тот же адрес, подпись «Энергия дня».
4. В репозитории → Settings → Secrets and variables → Actions → секреты:
   `TELEGRAM_BOT_TOKEN` и `BOT_DATA_KEY` (любая длинная секретная фраза: ею шифруется список подписчиков).
   Переменная `APP_URL` — адрес из шага 1 (по желанию).
5. Бот работает сам: каждые 10 минут задача «Бот и утренние сообщения» отвечает новым людям и рассылает
   утренние сообщения. Люди включают их в приложении: «Ещё» → «Утреннее сообщение».
